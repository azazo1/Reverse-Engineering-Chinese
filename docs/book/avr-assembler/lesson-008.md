# Lesson 008 - 倾斜开关

## 今天我们要做什么?

你有没有想过, 你的手机是怎么知道你把屏幕横过来看视频的? 数字水平仪又是怎么工作的?

今天我们要用一个**倾斜滚珠开关**做一个非常简单的姿态传感器. 传感器竖直放着的时候, 里面那颗小金属球滚开, 不碰电触点, 电路断开. 你把它倒过来, 金属球就滚到触点上, 把电路接通!

我们用这个传感器来控制板载 LED (Pin 13): 倾斜的时候点亮, 竖直的时候熄灭.

## 硬件检查: 它就是个按钮!

从单片机的角度看, 倾斜开关和第 005 课用的按钮是完全一样的东西.

区别只在于: 不是你的手指去按按钮把引脚接到地, 而是重力推着一颗金属球把引脚接到地.

既然它的行为就是一个开关, 接线方式也完全一样:
- 一条引脚接到 Arduino 的 **Pin 2 (PD2)**.
- 另一条引脚接到**地 (GND)**.
- 我们会打开 PD2 的**内部上拉电阻**, 这样当金属球*没有*碰到触点 (竖直) 时, 引脚读到的是高电平 (5 伏).

## 代码讲解

既然它基本就是个按钮, 代码写起来就轻松了!

### 1. 定义部分
```assembly
.equ DDRB,   0x04                      ; Port B 的数据方向寄存器
.equ PORTB,  0x05                      ; Port B 的数据寄存器
.equ PB5,    5                         ; Port B 的第 5 脚 (Arduino Pin 13 LED)
.equ PIND,   0x09                      ; Port D 的输入引脚寄存器
.equ DDRD,   0x0A                      ; Port D 的数据方向寄存器
.equ PORTD,  0x0B                      ; Port D 的数据寄存器
.equ PD2,    2                         ; Port D 的第 2 脚 (倾斜传感器)
```
我们为 LED 输出定义 `PB5`, 为倾斜传感器输入定义 `PD2`.

### 2. 设置输入和上拉
```assembly
  SBI    DDRB, PB5                     ; 把 PB5 (LED) 设为输出
  CBI    DDRD, PD2                     ; 把 PD2 (倾斜开关) 设为输入
  SBI    PORTD, PD2                    ; 使能 PD2 的内部上拉电阻
```
跟第 5 课一样, 我们把 `PB5` 设为输出, 把 `PD2` 设为输入, 并打开 `PD2` 的内部上拉. 这样一来, 竖直时 `PD2` 是高电平. 倾斜时, 金属球把电路接到地, `PD2` 变成低电平.

### 3. 读取传感器
```assembly
.loop:
  SBIC   PIND, PD2                     ; 若倾斜 (低电平) 则跳过下一条
  RJMP   .turn_off                     ; 若为高电平 (竖直) 就跳去熄灭
  SBI    PORTB, PB5                    ; 点亮 LED
  RJMP   .loop                         ; 重新开始循环
```
我们用 `SBIC` (位被清零就跳过) 来检查传感器.
如果传感器倾斜了, 引脚接到 GND, 变成低电平 (清零). `SBIC` 就会神奇地跳过 `RJMP .turn_off`, 直接落到 `SBI PORTB, PB5`, 把 LED 点亮!

如果传感器竖直, 上拉电阻把引脚保持在高电平 (置位). `SBIC` 什么也不做, 代码执行 `RJMP .turn_off`, 完全跳过点亮 LED 的那段.

```assembly
.turn_off:
  CBI    PORTB, PB5                    ; 熄灭 LED
  RJMP   .loop                         ; 重新开始循环
```
如果我们跳到了这里, 就把 LED 熄灭. 然后就一直循环下去!
