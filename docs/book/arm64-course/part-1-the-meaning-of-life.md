为什么是 C++? 我本职上主要用 Python 从事自动化开发, 然而随着每一天过去, 我们都会看到又一起勒索软件 (Ransomware) 攻击, 以灾难性的方式进一步使社会陷入瘫痪.

本 Course 是一个内容全面的系列, 我们会学习 C++ 的方方面面, 以及它与 ARM 64 架构之间的关系, 我们会用 ARM 64 汇编语言逐步逆向, 从而完整地理解这套环境.

全世界每天大约发生 2,000 多起入侵事件, 而真正从根本层面理解这些入侵如何实施的人却少之又少. 本 Course 将采用非常基础且循序渐进的方式, 带你理解与 ARM 64 相关的底层架构.
