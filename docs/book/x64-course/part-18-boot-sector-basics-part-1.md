在接下来的几节教程中, 我们将编写一个非常基础的 x86 操作系统, 为此我们会使用 QEMU, 它是一个全系统模拟器, 也就是操作系统模拟器. 你也可以安装 VirtualBox, 并且如果愿意, 最终把我们的引导程序转换成 ISO.

计算机启动的最核心部分就是我们所说的引导程序 (boot loader). 引导程序会从你的硬盘或其他介质上物理地读取第一个扇区, 也就是扇区 0, 最终引导起一个操作系统.

计算机启动时会读取第一个扇区, 它正好是 0x200 字节 (十六进制), 也就是十进制的 512 字节.

读取这个引导程序的系统被称为 BIOS, 也就是基本输入输出系统 (basic input output system), 它以 16 位模式加载. 这样做是为了兼容较老的处理器. 现代处理器会立即切换到我们所说的 UEFI, 它是一种更复杂的 IO 系统, 不过这里我们只关注 BIOS 的最基础知识.

下周我们将讨论 BIOS 读取引导扇区时到底发生了什么.
