那么... 一台 x64 服务器或计算机到底能理解什么? 0100010100100100101010, 还有更多...

再往上一层, 我们来到机器码 (machine code), 它是一串十六进制数字, 可以翻译成机器指令和/或数据.

有了 C 编程语言, 我们创造出一种构造, 能更容易地编写与硬件通信的程序. C 是现代几乎所有编程语言的祖父.

C 把 010101000101001011 这样的 x64 二进制, 或者 0x90 0x45 0x22 0x22 这样的机器码, 或者 mov rax, 0x222323123 这样的汇编等等, 全都抽象掉了...
