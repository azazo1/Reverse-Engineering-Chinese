到这里我们需要讨论一下内存. 在讨论如何在我们引导程序里搭建一个简单的栈之前, 我们必须理解引导扇区里的内存是如何分配的.

1)__0x0 = 中断向量表 (Interrupt Vector Table)__ - 这里就是我们的中断表所在之处, 位于内存的最底部. 我们所有的中断调用都存在于这里.

2)__0x400 = BIOS 数据区 (BIOS Data Area)__ - 这里存放关于可引导设备状态的变量.

3)__0x7c00 = 已加载的引导扇区 (Loaded Boot Sector)__ - 这里存放我们的机器码, 它会被引导程序固件加载到 RAM 里 (注意: 固件就是操作系统运行之前先运行的代码, 就像我们现在写的这样).

4)__0x7e00 = 空闲 (Free)__ - 这是你可以用来开发的栈区.

5)__0x9fc00 = 扩展 BIOS 数据区 (Extended BIOS Data Area)__ - 存放来自磁盘磁道缓冲区和其他已连接设备的数据, 记住到目前为止还没有文件系统.

6)__0xa0000 = 视频内存 (Video Memory)__ - BIOS 在启动时把你的视频内存映射到这里.

7)__0xc0000 = BIOS__ - BIOS 正式所在的位置.

8)__0x100000 = 空闲__ - 你可以用来开发的额外空间.
