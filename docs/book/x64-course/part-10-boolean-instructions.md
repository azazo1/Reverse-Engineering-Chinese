## Part 10 - 布尔指令

布尔指令共有四条, 分别是 AND, OR, XOR 和 NOT. 在本教程前面我们简要讨论过逻辑门, 它们在底层利用了同样的逻辑. 在之后的逆向过程中我们会不断看到这种逻辑, 因此理解它在单个二进制位层面上的作用很重要.

AND = 如果第一个数是 0 且第二个数是 0, 结果为 0.

AND = 如果第一个数是 0 且第二个数是 1, 结果为 0.

AND = 如果第一个数是 1 且第二个数是 0, 结果为 0.

AND = 如果第一个数是 1 且第二个数是 1, 结果为 1.

ex: 0 0 1 0 0 0 1 0

ex: 0 1 1 0 1 1 1 0

ex:-------

ex: 0 0 1 0 0 0 1 0

OR = 如果第一个数是 0 且第二个数是 0, 结果为 0.

OR = 如果第一个数是 0 且第二个数是 1, 结果为 1.

OR = 如果第一个数是 1 且第二个数是 0, 结果为 1.

OR = 如果第一个数是 1 且第二个数是 1, 结果为 1.

ex: 0 0 1 0 0 0 1 0

ex: 0 1 1 0 1 1 1 0

ex:-------

ex: 0 1 1 0 1 1 1 0

XOR = 如果第一个数是 0 且第二个数是 0, 结果为 0.

XOR = 如果第一个数是 0 且第二个数是 1, 结果为 1.

XOR = 如果第一个数是 1 且第二个数是 0, 结果为 1.

XOR = 如果第一个数是 1 且第二个数是 1, 结果为 0.

ex: 0 0 1 0 0 0 1 0

ex: 0 1 1 0 1 1 1 0

ex:-------

ex: 0 1 0 0 1 1 0 0

NOT = 如果第一个数是 0, 第二个数就变成 1.

NOT = 如果第一个数是 1, 第二个数就变成 0.

ex: 0 0 1 0 0 0 1 0

ex:-------

ex: 1 1 0 1 1 1 0 1
