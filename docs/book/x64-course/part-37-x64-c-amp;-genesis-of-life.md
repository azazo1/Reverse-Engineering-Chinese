## Part 37 - x64 C &amp; 生命的起源

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

恭喜你, 你写出, 编译并修改了自己的第一个 C++ 程序. 本教程接下来的部分, 我会专注于所有编程语言之父: 从 "Hello World" 到 Web 服务器, 用的都是那门所有现代语言都源自它的语言, 也就是 C.

就像宗教有各种流派一样, 编程语言也有各种各样的. 不过总有一个 ROOT 宗教或者说根语言, 万物都由它派生出来, 那就是 C. 在接下来的几个月里, 我会教你 C, 并对每个二进制文件做逆向工程, 让你掌握这门万物的 MASTER 语言.

当我们需要在敏捷环境里开发时, 当然会用 Java 或 Python, 或者任何其他快速开发语言; 但如果你想精通网络工程 (Cyber Engineering), 你就必须与 WORD 合一, 用数字和网络世界的话说, 这个 WORD 就是 C 编程语言.

你可以把 C 想象成在教堂里, 而 Python, Java 或 C\# 则是在世俗环境里. C 能让你对自己的程序或环境拥有完全, 彻底的控制力, 而 Java 或 Python 只能提供部分控制; 不过在如今快速开发业务逻辑的环境里, 它们是必不可少的语言.

下一节 Lesson 里, 我们会像上一节那样, 从最基础的 "hello world" 程序开始, 只不过这次用的是 C. 记住爱因斯坦的话 - "__我想知道上帝的想法, 其余的只是细节.__" 这就是 C 和其他任何语言的区别: 你坐的位置正是便携系统工程设计的最 ROOT 处!
