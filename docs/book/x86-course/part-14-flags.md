## Part 14: 标志位

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

在逆向工程中, 标志位是汇编语言和程序流程控制里最极端复杂且难以理解的概念之一. 当我们进入训练的最后阶段, 把 C 应用程序逆向成汇编语言时, 下面的这些内容会变得清晰得多.

这里重要的是要记住, 标志位有助于控制, 检查和验证程序的执行, 它是一种判断处理器所执行的每一项操作是否成功的机制.

标志位对汇编语言应用程序至关重要, 因为它们是验证每个程序函数是否成功执行的检查手段.

我们面对的是 32 位汇编, 其中存在一个 32 位寄存器, 里面包含一组状态标志位, 控制标志位和系统标志位. 这个寄存器被称为 EFLAGS 寄存器, 因为它包含 32 位信息, 这些位被映射来表示特定的标志信息.

标志位有三类, 分别是状态标志位, 控制标志位和系统标志位.

状态标志位如下:

__CF__: 进位标志位 (Carry Flag)

__PF__: 奇偶标志位 (Parity Flag)

__AF__: 调整标志位 (Adjust Flag)

__ZF__: 零标志位 (Zero Flag)

__SF__: 符号标志位 (Sign Flag)

__OF__: 溢出标志位 (Overflow Flag)

当对无符号整数值进行数学运算, 最高有效位产生进位或借位时, 进位标志位会被置位. 对于参与该数学运算的寄存器来说, 这是一种溢出状况. 当这种情况发生时, 寄存器中剩下的数据并不是该数学运算的正确答案.

奇偶标志位用于指示寄存器中因数学运算而受损的数据. 检查时, 如果结果中 1 的总个数为偶数, 奇偶标志位就被置位; 如果结果中 1 的总个数为奇数, 它就被清零. 通过检查奇偶标志位, 应用程序可以判断寄存器在这次运算之后是否已被破坏.

调整标志位用于二进制编码的十进制 (Binary Coded Decimal) 数学运算, 如果用于计算的寄存器第 3 位发生进位或借位, 它就会被置位.

如果运算结果为零, 零标志位就会被置位.

符号标志位被设置为结果中的最高有效位, 也就是符号位, 它表示结果是正数还是负数.

溢出标志位用于有符号整数算术运算, 当正值太大或负值太小, 无法用该寄存器表示时就会用到它.

控制标志位用于控制处理器中的特定行为. DF 标志位, 也就是方向标志位 (direction flag), 用于控制处理器处理字符串的方式. 当它被置位时, 字符串指令会自动递减内存地址, 以取得字符串中的下一个字节. 当它被清零时, 字符串指令会自动递增内存地址, 以取得字符串中的下一个字节.

系统标志位用于控制操作系统层面的操作, 任何程序或应用程序都绝不应该修改它们.

__TF__: 陷阱标志位 (Trap Flag)

__IF__: 中断使能标志位 (Interrupt Enable Flag)

__IOPL__: I/O 特权级标志位 (I/O Privilege Level Flag)

__NT__: 嵌套任务标志位 (Nested Task Flag)

__RF__: 恢复标志位 (Resume Flag)

__VM__: 虚拟 8086 模式标志位 (Virtual-8086 Mode Flag)

__AC__: 对齐检查标志位 (Alignment Check Flag)

__VIF__: 虚拟中断标志位 (Virtual Interrupt Flag)

__VIP__: 虚拟中断挂起标志位 (Virtual Interrupt Pending Flag)

__ID__: 标识标志位 (Identification Flag)

陷阱标志位被置位时会启用单步模式, 在这种模式下处理器一次只执行一条指令代码, 然后等待信号再执行下一条指令. 这在调试时至关重要.

中断使能标志位控制处理器如何响应来自外部源的信号.

I/O 特权字段表示当前正在运行任务的输入输出特权级, 它定义了输入输出地址空间的访问级别, 该级别必须小于或等于访问相应地址空间所需的访问级别. 如果它不小于也不等于所需的访问级别, 任何访问该地址空间的请求都会被拒绝.

嵌套任务标志位控制当前正在运行的任务是否与先前执行的任务相链接, 用于串联被中断的任务和被调用的任务.

恢复标志位控制处理器在调试模式下如何响应异常.

VM 标志位表示处理器正运行在虚拟 8086 模式, 而不是保护模式或实模式.

对齐检查标志位与 CR0 控制寄存器中的 AM 位配合使用, 以启用对内存引用的对齐检查.

当处理器运行在虚拟模式时, 虚拟中断标志位复制 IF 标志位.

虚拟中断挂起标志位在处理器运行于虚拟模式时使用, 用于表示有一个中断正在挂起.

ID 标志位表示处理器是否支持 CPUID 指令.
