## Part 19 - 为什么要学汇编

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

为什么要学汇编语言? Java 是最抢手的编程语言, 能让我立刻找到工作, 那我到底为什么要浪费该死的时间去学这种老掉牙的汇编语言垃圾?

很多人问过我这个问题, 而且确实如此, Java 很火, 需求也最大, 学 Java 没有任何问题, 但在这个世界上, 比任何东西都更威胁社会的, 是网络安全威胁. 话虽如此, Java 提供了一条很好的职业道路, 我会鼓励你去学它, 不过 Java 并不是唯一的选择.

大多数恶意软件是用高级语言编写的, 但大多数恶意软件作者不会把源代码交给攻击者, 让他们能妥善应对其精心构造的攻击.

攻击者们会使用各种各样的高级语言, 而对新的职业恶意软件分析师和逆向工程师的需求每天都在增长.

我们分析恶意软件时, 得到的往往只是一个编译好的二进制文件. 对编译好的二进制文件, 我们唯一能做的就是把它逐条指令地拆解成汇编语言, 因为所有东西最终都会落到汇编语言上.

当有人说汇编语言是恐龙时, 我对那些人说: 等你整个网络被彻底打垮, 你一个终端都登不上, 网络上任何一台机器都操纵不了的时候, 我们再来聊这个话题. 到那时我们再来谈谈汇编语言到底有多没用.

理解汇编语言能让人对一个正在运行的进程打开调试器. 每个正在运行的程序都有一个 PID, 它是一个数值, 用来标识正在运行的程序. 如果我们用 GDB 这样的专业工具或开源工具打开一个正在运行的进程或者任何一段恶意软件, 我们就能看清楚究竟发生了什么, 然后抓住 EIP 指令指针去我们想去的地方, 从而完全控制程序的执行流.

正如我所说, 大多数恶意软件是用中级语言编写的, 一旦编译完成, 它就可以被硬件或操作系统读取, 因为它不是人类可读的. 为了让专业的网络安全工程师理解它, 他们必须学会阅读, 编写并妥善调试汇编.

汇编语言是低级的, 它包含的指令比你在高级应用程序中看到的要多得多.

本教程系列的前 18 节 Lesson 给了你 x86 硬件的基础知识. 正如我在之前的教程中所说, 我们会专注于 32 位汇编调试, 因为大多数恶意软件都会试图影响尽可能多的系统, 虽然存在 64 位恶意软件, 但 32 位恶意软件的破坏性和危险性要大得多, 本系列将聚焦于此.
