## Part 11: 段寄存器

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

段寄存器 (segment register) 专门用于引用内存位置. 访问系统内存有三种不同的方法, 其中我们将聚焦于平坦内存模型 (flat memory model), 因为它与我们的目的相关.

共有六个段寄存器, 如下所示:

__CS__: 代码段寄存器 (Code segment register) 保存代码段 (.text 段) 的基址位置, 用于数据访问.

__DS__: 数据段寄存器 (Data segment register) 保存变量的默认位置 (.data 段), 用于数据访问.

__ES__: 附加段寄存器 (Extra segment register), 在字符串操作期间使用.

__SS__: 栈段寄存器 (Stack segment register) 保存栈段的基址位置, 在隐式使用栈指针或显式使用基址指针时使用.

__FS__: 附加段寄存器.

__GS__: 附加段寄存器.

每个段寄存器都是 16 位的, 其中包含指向某个特定内存段起点的指针. CS 寄存器包含指向内存中代码段的指针. 代码段就是内存中存放指令代码的地方. 处理器根据 CS 寄存器的值, 以及指令指针 (EIP) 寄存器中包含的偏移值, 从内存中取出指令代码. 请记住, 任何程序都不能显式加载或修改 CS 寄存器. 当程序被分配内存空间时, 处理器会为它赋值.

DS, ES, FS 和 GS 段寄存器都用于指向数据段. 这四个各自独立的数据段帮助程序分隔数据元素, 以确保它们不会重叠. 程序为这些段把相应的指针值加载到数据段寄存器中, 然后使用偏移值来引用各个内存位置.

栈段寄存器 (SS) 用于指向栈段. 栈中保存传递给程序内各函数和过程的数据值.

段寄存器被认为是操作系统的一部分, 在几乎所有情况下, 既不能直接读取, 也不能直接修改. 在保护模式平坦模型 (32 位的 x86 架构) 下工作时, 你的程序会获得 4GB 的地址空间, 任何一个 32 位寄存器都可能寻址到这四十亿个内存位置中的任意一个, 操作系统所定义的那些受保护区域除外. 物理内存可能大于 4GB, 但一个 32 位寄存器只能表示 4,294,967,296 个不同的位置. 如果你的计算机内存超过 4GB, 操作系统必须在内存中安排出一个 4GB 的区域, 而你的程序被限制在这个新区域内. 这项任务由段寄存器完成, 操作系统对此保持严密控制.
