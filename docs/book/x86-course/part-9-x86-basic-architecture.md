## Part 9: x86 基本架构

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

计算机应用程序不过是一张存储在内存中的机器指令表, 组成程序的那些二进制数之所以特殊, 仅仅在于 CPU 处理它们的方式.

基本架构由 CPU, 内存和 I/O 设备组成, 也就是输入/输出设备, 它们都由系统总线连接, 详见下文.

CPU 由 4 个部分组成:

1) 控制单元 - 从 CPU 中取出并译码指令, 然后把它们存入内存以及从内存中取回.

2) 执行单元 - 取指令和读指令的执行在这里发生.

3) 寄存器 - CPU 内部的存储位置, 用作临时数据存储.

4) 标志位 - 在执行发生时指示各种事件.

<div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520178351635.jpg"/></div>

我们将讨论 32 位 x86, 因此一个 32 位 CPU 首先从内存中的某个特定地址取一个双字 (长度为 4 字节, 也就是 32 位), 它从内存中读出并装入 CPU. 此时 CPU 会查看这个双字内部的二进制位模式, 并开始执行所取到的机器指令指示它去做的过程.

一条指令执行完成后, CPU 会去内存中按顺序取下一条机器指令. CPU 有一个寄存器 (我们会在未来的教程中讨论寄存器), 叫做 EIP, 也就是指令指针, 它保存着下一条要从内存中取出并执行的指令的地址.

我们立刻就能看出, 如果我们控制了 EIP 的流向, 就能改变程序, 让它做自己原本绝不打算做的事. 这是恶意软件所依赖的一种常见手法.

整个取指与执行的过程都与系统时钟绑定, 系统时钟是一个振荡器, 以精确的间隔发出方波脉冲.

在下一个教程中, 我们将通过讨论通用寄存器来更深入地探讨 IA-32 架构.
