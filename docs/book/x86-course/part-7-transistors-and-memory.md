当我们问自己什么是计算机时, 必须回到最最基本的层面.

电子计算机不过是由晶体管开关构成的. 晶体管是微小的硅晶体, 利用硅的电学特性来充当开关. 现代计算机使用的是所谓的场效应晶体管.

我们以 3 个引脚为例. 当给引脚 1 施加电压时, 电流就会在引脚 2 和引脚 3 之间流动. 当第一个引脚上的电压被撤去时, 引脚 2 和引脚 3 之间的电流就停止了.

当我们把视野拉远一些, 会看到还有二极管和电容; 把它们与晶体管开关结合起来看, 我们就得到了一个存储单元. 存储单元会维持一个最小的电流. 当你在它的输入引脚上施加一个小电压, 并在它的选择引脚上施加一个相近的电压时, 它的输出引脚上就会出现并保持一个电压. 只要不从输入引脚和选择引脚上撤去电压, 输出电压就会一直保持在被设定的状态.

你可能会问, 这为什么重要. 很简单, 有电压表示二进制的 1, 没有电压表示二进制的 0, 因此存储单元保存的是一位二进制数字, 也就是一个比特, 它要么是 1 要么是 0, 意味着开或关.
