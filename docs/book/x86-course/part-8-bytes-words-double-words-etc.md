## Part 8 - 字节, 字, 双字等等...

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

内存以字节为单位度量. 一个字节是 8 位. 两个字节称为一个字, 两个字称为一个双字, 也就是四个字节 (32 位), 而四字是八个字节 (64 位).

一个字节是 8 位, 也就是 2^8, 等于 256. 大小为 8 位的二进制数共有 256 个取值, 从 0 开始一直到 255.

计算机中的每个内存字节都有自己唯一的地址. 我们通过在 main 函数上设置断点, 来回顾 Linux 下一个简单 hello world 程序的反汇编指令. 我们将使用 GDB 调试器:

如果现在还看不明白, 不用担心. 用这个例子的目的是让你先睹为快, 看看我们将要分析的第一个程序, 同时也了解计算机中的内存.

下面是对 ESP 寄存器的一次查看. 再说一次, 现在不理解什么是寄存器, 或者 ESP 起什么作用, 并不重要. 我们只是想看看一个内存位置长什么样:

![](/imgs/1520519298916.jpg)&nbsp;

我们看到内存位置 0xffffd040, 它当然是十六进制的. 我们还看到 ESP 寄存器里的值 0xf7fac3dc, 它同样是十六进制的.

重要的是要理解, 0xffffd040 是 4 个字节, 是一个双字. 正如我们在 Part 6: 十六进制数制中学到的, 每个十六进制数字都是 4 位长, 也叫一个半字节. 在 0xffffd040 中, 我们看最右边的数字 0. 在这个例子里, 0 (十六进制) 是 4 位长. 如果我们看 40 (十六进制), 可以看到它是一个字节的长度, 也就是 8 位长. 如果我们看 d040, 我们有两个字节, 也就是一个字的长度. 最后, ffffd040 是一个双字, 也就是 4 个字节的长度, 即 32 位长. 地址开头的 0x 只是表示它是一个十六进制值.

计算机程序不过是存储在内存中的机器指令. 一个 32 位 CPU 会从某个内存地址取一个双字. 双字是连续的 4 个字节, 从内存中读出并装入 CPU. 一旦它执行完毕, CPU 就会根据指令指针从内存中取下一条机器指令.
