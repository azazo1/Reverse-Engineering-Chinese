## Part 5: 二进制数制

关于所有 Lesson 的完整目录, 请点击下方链接, 它会给出每节 Lesson 的简介, 以及将涵盖的主题.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

二进制数定义了计算机的核心. 计算机中的一个比特要么是开, 要么是关. 一个比特要么有电流通过, 要么没有电流. 我们会在未来的教程中更深入地探讨这些内容.&nbsp;

又困惑又迷茫, 我们该从哪里往下走呢?

别怕! 二进制数制来了! 重要的是要理解, 在二进制中每一列的值都是它右边一列的两倍, 而这个进制里只有两个数字, 恰好是 0 和 1.

在十进制也就是 10 进制中, 假设我们有数字 15, 它表示 (1 x 10) + (5 x 1) = 15, 因此 5 是这个数字乘以 1, 而 1 是这个数字乘以 10.

二进制的运作方式与之类似, 只不过现在我们说的是 2 进制. 同一个数字在二进制中就是 1111. 图示如下:&nbsp;

二进制数之所以重要, 是因为用它们代替十进制可以简化计算机及相关技术的设计. 二进制数制最简单的定义是: 一种只使用两个数字 (如上所述) 来表示计算机体系结构所需数字的计数系统&nbsp;而不是用 1 到 9 再加上 0 这些数字来表示.
