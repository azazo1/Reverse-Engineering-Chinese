要很好地理解汇编语言, 以及为什么理解这些基础内容很重要, 需要涵盖的&nbsp;内容非常多.

我们必须回答的第一个问题是, x86 汇编语言是什么, 而答案是, 它是一组向后兼容的汇编语言, 能够一直兼容到 Intel 8000 系列微处理器. x86 汇编语言用于为上述系列处理器生成目标代码. 它使用助记符来表示 CPU 能够执行的指令.

用于 x86 微处理器的汇编语言会与各种操作系统配合工作. 我们将重点关注使用 Intel 语法的 Linux 汇编语言, 同时学习如何用 C 编程, 之后我们会把源代码反汇编, 并分析相应的汇编代码.

x86 汇编语言有两种语法可选. AT&amp;T 语法在 Unix 世界里占据主导, 因为 Unix 操作系统就是在 AT&amp;T 贝尔实验室开发的. 相比之下, Intel 语法最初用于 x86 平台的文档, 并在 MS-DOS 和 Windows 环境中占据主导.

就我们的目的而言, 当我们最终反汇编或调试软件时, 不论身处 Linux 还是 Windows 环境, 我们看到的绝大部分都是 Intel 语法. 无论我们分析的是 PE 格式的 Windows 二进制文件, 还是 ELF 格式的 Linux 二进制文件, 这一点都至关重要. 本教程后面还会详细讲到.

两者的主要区别在于, 在 AT&amp;T 语法中源操作数在前, 目的操作数在后; 而在 Intel 语法中目的操作数在前, 源操作数在后. 我们会在本教程后面更详细地讨论这一点.

我们会重点讲 Linux 汇编, 因为 Linux 能在各种硬件上运行, 能够驱动手机, 个人电脑或复杂的商用服务器这类设备.

Linux 还是开源的, 而且有很多版本. 在演示中我们会重点使用 Ubuntu, 它可以免费获取. 相比之下, Windows 操作系统由 Microsoft 一家公司拥有和控制, 所有更新, 安全补丁和服务补丁都直接来自他们; 而 Linux 有数百万专业人员提供同样的东西, 而且完全免费!
