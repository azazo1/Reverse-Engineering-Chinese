欢迎来到 ARM 逆向工程教程. 这是我做的第三个教程系列, 聚焦于汇编语言与逆向工程.

第一个系列讲的是 x86 汇编, 第二个系列讲的是 ARM 汇编. 本系列是 ARM 方向上的扩展系列, 聚焦 ARM 逆向工程, 所以我们不再单用汇编直接编写程序, 然后再用汇编去逆向那个二进制, 而是把汇编与 C 放在一起用, 再用汇编来做逆向, 这样你就能体会到真实世界里的一类应用是什么样, 以及它们被反汇编后是什么样子.

我们不会使用 IDA Pro 这类 GUI 工具, 而是使用 CLI shell 里的 GDB. 我们也不会在传统实验环境里把一个二进制丢进调试器, 而是 SSH 登录到 ARM 设备, 真正附加 (attach) 到一个正在运行的进程 (PID) 上, 在进程运行时对它做逆向.

前 13 周会完整复习 ARM 汇编系列, 因为重新审视这些概念至关重要, 只有这样, 到了逆向二进制的时候, 我们才能有一个非常牢固的把握.

在开始之前, 我想再次引用下面这段原话...

"那么, 如果我上大学去学 Java, 我就能赚到一百万, 拥有各种好东西吗?"

我觉得有必要用这样一句话来开启这个教程系列. 这并不是在攻击 Java, 因为我在 Android 开发, Spring 和 JavaEE 里都用过 Java. 在如今的敏捷环境里, 快速开发就是现实. 随着商业市场和政府部门面临的挑战不断增加, 软件开发会继续把重心放在更健壮的库上, 用更少的资源做更多的事. 随着项目交付的竞赛每分每秒都在加剧, React, Python, Java, C\# 这类东西会继续增长而不是萎缩.

不管你喜不喜欢, 硬件正变得越来越小, 趋势也正从 CISC 走向 RISC. CISC 就是你熟悉的 x86/x64 计算机, 带有一套复杂的指令. CISC 计算机会一直存在, 但趋势正在走向云计算, 加上如今具有精简指令集的 RISC 机器已经如此强大, 它们显然是消费端的首选.

你觉得今天地球上存在多少部手机? 其中大多数都是 RISC 机器. 你们中有多少人拥有智能电视, Amazon Echo, 或者其他各式各样被视为 IOT 即 Internet Of Things (物联网) 一部分的设备? 这些设备都有一个共同点 - 它们都是 RISC, 而且主要都基于 ARM.

ARM 是进阶 RISC 机器 (advanced RISC machine). 与 CISC 那种非常复杂的架构相比, 今天大多数 ARM 系统都是所谓的 SoC 或 system on chip (片上系统), 也就是一种集成电路, 它把一台计算机和电子系统的全部组件都放在单个芯片上. 这其中也包括 RF 功能. 这些低功耗嵌入式设备可以运行 Windows, Linux 以及许多其他高级操作系统的版本.

"好吧, 谁在乎 ARM 呢, 你爱怎么叫它就怎么叫它, 我会 Java, 这就是我需要知道的全部, 因为我写程序的时候它到处都能跑, 所以我根本不用操心底层发生了什么."

我还是想请你花片刻时间回味一下上面这段话. 日子一天天过去, 越来越多的系统变得容易遭受攻击和入侵. 花时间去理解底层发生了什么, 只会有助于遏制这种不幸的现实.

本系列聚焦 ARM 逆向工程. 我们会使用 Raspberry Pi 3, 它搭载 Broadcom BCM2837 SoC, 带有 4x ARM Cortex-A53, 1.2GHz CPU 和 1 GB LPDDR2 RAM. 我们会使用基于 Linux 的 Raspbian Jessie 操作系统. 如果你没有 Raspberry Pi 3, 它们通常以 35 美元的价格在 Amazon 或任何一家零售商处就可以买到. 如果你想了解更多, 请访问 <a href="https://www.raspberrypi.org/" rel="nofollow noopener" target="_blank">https://www.raspberrypi.org</a>.

我们将只在终端里工作, 所以没有漂亮的图片和图形, 因为我们要坚持硬核的极简方式, 使用 GNU 工具链来编译和调试我们的代码库.
