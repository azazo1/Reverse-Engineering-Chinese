## Part 2 - 数制

微处理器的核心是一连串二进制数, 它们要么是 +5V (开, 也就是 1), 要么是 0V (关, 也就是 0). 每个 0 或 1 都代表微处理器里的一位 (bit) 信息. 8 位组合起来就是一个字节 (byte).

在深入二进制之前, 先来看看我们熟悉的十进制. 拿 2017 这个数来说, 我们会把它理解为两千零一十七.

我们来看一看二进制系统, 以及它运作的基本原理.

如果要把一个二进制数转成十进制, 做法非常简单, 就像下面这样. 以二进制数 0101 1101 为例, 可以看到它对应十进制的 93.

<div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520212802125.jpg"/></div>

把数值列里的数相加, 得到 0 + 64 + 0 + 16 + 8 + 4 + 0 + 1, 结果是十进制的 93.

如果要把十进制数转成二进制, 我们会对照最高位判断能不能做一次减法, 如果能, 就在对应的二进制列写 1, 余数则带到下一行. 以十进制数 120 为例, 它对应的二进制是 0111 1000.

<div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520194446121.jpg"/></div>

1) 128 能装进 120 里吗: 不能, 因此为 0.

2) 64 能装进 120 里吗: 能, 因此为 1, 然后 120 - 64 = 56.

3) 32 能装进 56 里吗: 能, 因此为 1, 然后 56 - 32 = 24.

4) 16 能装进 24 里吗: 能, 因此为 1, 然后 24 - 16 = 8.

5) 8 能装进 8 里吗: 能, 因此为 1, 然后 8 - 8 = 0.

6) 4 能装进 0 里吗: 不能, 因此为 0.

7) 2 能装进 0 里吗: 不能, 因此为 0.

8) 1 能装进 0 里吗: 不能, 因此为 0.

要把二进制转成十六进制, 只需对照下面这张表.

<div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520211831076.jpg"/></div>

我们把 0101 1111 这样的二进制数转成十六进制. 做法就是查表, 逐个比较每个半字节 (nibble), 一个半字节由 4 位组成. 记住, 8 位等于一个字节, 2 个半字节也等于一个字节.

0101 = 5

1111 = F

因此二进制 0101 1111 = 十六进制的 0x5f. 0x 这种写法表示十六进制.

从十六进制回到二进制也很简单, 只要反过来做一遍就行, 例如:

0x3a = 0011 1010

3 = 0011

A = 1010

要明白一点: 每个十六进制数字的长度是一个半字节, 因此两个十六进制数字的长度是一个字节.

从十六进制转成十进制, 做法如下:

0x5f = 95

5 = 5 x 16^1 = 5 x 16 = 80

F = 15 x 16^0 = 15 x 1 = 15

可见 80 + 15 = 95, 也就是十六进制的 0x5f.

最后是从十进制转成十六进制. 以十进制数 850 为例, 它等于十六进制的 352.

<div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520238915130.jpg"/></div>

把数字从下往上拼起来, 就得到十六进制的 352.

"计算机都替我把这些算好了, 我干嘛还要浪费时间学这些鬼东西!"

如果你身边有做逆向工程 (Reverse Engineering) 的人, 不妨抽点时间, 把上面这个问题拿去问问他们.

事实是, 如果你对上面这些内容的运作方式没有非常扎实的理解, 就很难搞懂 ARM 处理器的寄存器是如何保存和操作数据的. 你也很难搞懂 ARM 处理器如何处理二进制溢出, 以及溢出对进位操作的影响; 你既不会理解比较操作是怎么工作的, 也看不懂最简单的汇编代码里最基本的操作.

我不是让你把上面这些背下来, 也不是让你每种都做上千道练习. 我只希望你花点时间真正明白: 处理器里的一切, 真的是字面意义上的一切, 最终都归结为二进制位.

无论你是在编写, 调试还是修改用汇编, Python, Java, C, C++, R, JavaScript, 或者任何其他刚问世的新语言写成的应用, 一切最终都必然归结为二进制的 0 和 1, 它们分别代表 +5V 和 0V.

我们人类使用 10 进制, 也就是十进制. 处理器使用 16 进制 (十六进制). 我们配合 Linux 打交道的这些寄存器, 按 32 位大小寻址. 等开始讨论处理器寄存器时, 我们会了解到每个寄存器都是 32 位宽 (严格说 BCM2837 是 64 位宽, 但我们所用的这个 Linux 版本是 32 位的, 因此每个寄存器只涉及 32 位).
